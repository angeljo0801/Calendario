# Calendario

Aplicación Android para convertir texto compartido en un recordatorio/evento de calendario.

## Flujo principal

1. Selecciona texto en cualquier aplicación Android.
2. Toca **Compartir**.
3. Elige **Calendario**.
4. Revisa o edita el título, nota, fecha, hora y calendario.
5. Guarda y el evento se crea directamente en el calendario elegido del teléfono.

## Privacidad

La app funciona localmente. No requiere cuenta propia, servidor ni API externa.
